# Slide 24 Puzzle (5×5 Sliding Number Tray)

A classic tactile **5×5 (24-tile)** sliding number puzzle inspired by physical wooden sliding trays, with smooth multi-tile row/column sliding, swipe & keyboard controls, and 4 customization options per category.

## Features
- **4 Board Modes:** `3×3` (8 tiles), `4×4` (15 tiles), `5×5` (24 tiles — default), and `6×6` (35 tiles), plus a **Photo 5×5** preset matching the exact board state from the reference photo.
- **4 Tray Materials:** `Classic Sandwood`, `Obsidian Cyber`, `Royal Emerald`, and `Ivory & Walnut`.
- **4 Tabletop Backgrounds** and **4 Player Profiles**.
- **Smart Hint**, **Undo**, **Move & Timer Tracking**, and persistent best records.

## Run
Double-click `run_app.bat` or run:
```bash
flutter run -d chrome
```
